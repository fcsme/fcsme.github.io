# FCSME Website

Static, responsive website for the Frederick County Society of Model Engineers. It uses HTML and CSS with no build step.

## Run locally

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`.

## Files

- `index.html`: content and structure
- `styles.css`: responsive design
- `favicon.svg`: browser icon
- `assets/images/`: club graphics and photography

## Design

- Blue: `#333366`
- Yellow: `#CCCC33`
- Body: system sans-serif
- Headings: Georgia

The colors are the nearest web-safe matches to the supplied club palette. Railroad details remain subtle: photography, a track rule, the timeline, and the footer illustration.

## Content

Facebook supplies the address and email. Club material supplies layout details. The Frederick News-Post and Frederick's Child supply the 2022 move history. Current hours and events remain on Facebook and Instagram.
